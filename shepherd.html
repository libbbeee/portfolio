Project Overview

Project: Shepherd, a 2D puzzle/arcade game

My Roles: Game Designer, Systems Designer, Game Developer

Timeline: 8 weeks (2025)

Shepherd is a game where the player plays as a sheep herding dog and rounds up all the sheep in a field into a barn within a time limit.

  • Mechanics
  • C#
  • Unity
  • Systems

My Contributions

Systems Design

When Shepherd enters a certain radius of the sheep, they run in the opposite direction. I designed the game loop around herding the sheep within a time limit. This balances tension and critical thinking as players find the optimal route before nightfall.

Level Design

Each level has a different number of sheep, a different time limit, and a different layout. My goal was to create initial levels that helped the player learn the mechanics, followed by increasingly difficult levels with new obstacles to keep the player engaged. I balanced the initial level difficulties with spreadsheets and designed new challenges to add to levels, like lakes and rivers.

Development

After completing the design of Shepherd, I developed the initial levels of the game in Unity. This included coding in C#, UI, tilesets, and more. The development process was iterative, with consistent playtesting to get user feedback on the project.
